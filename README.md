# Trabalho 45RPE - Severance

Trabalho da disciplina de Resolução de Problemas com Estruturas de Dados (UDESC).

O objetivo é extrair e analisar a rede de interações entre os personagens da 1ª temporada da série *Severance* usando Python e NetworkX, a partir das legendas dos episódios.

## Estrutura

- `data/` - legendas (.srt) e base de dados de interações (.txt)
- `docs/` - enunciado do trabalho e artigo de referência
- `src/` - scripts de extração
- `notebooks/` - notebook com as análises (a fazer)
